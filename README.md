# C++ Async Chat Server

Многопользовательский TCP-чат на **C++17** и Linux `epoll` без потока на каждого клиента. Включает сервер, консольный клиент и простой нагрузочный скрипт.

## Сборка

Требуются Linux, CMake 3.16+ и компилятор C++17.

```bash
cmake -S . -B build
cmake --build build -j
```

## Запуск

В первом терминале:

```bash
./build/chat-server 9000
```

Во втором и третьем:

```bash
./build/chat-client 127.0.0.1 9000
```

Введите ник, затем сообщения. Доступны `/who`, `/msg <ник> <текст>` и `/quit`. Для быстрой проверки можно использовать `nc 127.0.0.1 9000`. Спецификация сообщений находится в `docs/protocol.md`.

## Архитектура

- Один event loop на базе `epoll` обслуживает слушающий сокет и множество клиентских соединений. Все сокеты неблокирующие.
- Клиентские строки накапливаются до `\n`; длинные строки отклоняются.
- Очередь исходящих сообщений ограничена 1 МиБ на клиента. Медленный читатель отключается, чтобы не задерживать остальных.
- Регистрация ника, широковещательные и приватные сообщения обрабатываются в том же потоке. Подключения и отключения пишутся в `chat-server.log`.
- Чат работает по TCP и не шифрует трафик; для использования в интернете добавьте TLS-терминацию и ограничения доступа.

## Как измерить

Запустите сервер и в другом терминале:

```bash
python3 tests/load_test.py --clients 100
```

Скрипт создаёт заданное число соединений, регистрирует ники, проверяет `/who` и выводит время подключения. Увеличивайте `--clients`, пока не достигнете ограничений машины или лимита файловых дескрипторов (`ulimit -n`). Результат зависит от оборудования и лимитов ОС; выдуманные значения производительности здесь не приводятся.
