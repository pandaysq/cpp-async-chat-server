# Текстовый протокол

Соединение — обычный TCP. Кодировка сообщений — UTF-8, разделитель — `\n` (также принимается `\r\n`).

1. После подключения сервер просит указать ник. Первый отправленный клиентом текстовый ряд считается ником. Разрешены латинские буквы, цифры, `_`, длина 1–24 символа. Регистр при проверке занятости не учитывается.
2. Обычная строка отправляется всем вошедшим пользователям: `[Nick] hello`.
3. `/who` выводит список присутствующих: `Online: Nick Other`.
4. `/msg Other text` отправляет личное сообщение пользователю `Other`; отправитель получает подтверждение.
5. `/quit` закрывает соединение.

Сервер отклоняет строки длиннее 4096 байт и отключает клиента, у которого накопилось более 1 МиБ неотправленных сообщений (backpressure), чтобы медленный читатель не заблокировал остальных. Сообщения сохраняются только в памяти на время соединения. Логи подключений и отключений записываются в `chat-server.log`.
